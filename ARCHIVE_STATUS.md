# Publication scope

Neural-Lingua now includes an independently authored learning companion for the 52 original VOA Level 1 videos and a browser translator. Media remains in official remote players. Source rights, HTTP metadata and representative real playback are documented separately.

The local preview binds only 127.0.0.1. The public course is packaged separately by tools/build_public.py for a new, manually deployed Netlify project: https://neural-lingua-course.netlify.app/. Publication is gated by the version-bound security report and exactly three independent review rounds. No learner accounts, database, audio upload endpoint, paid services or local AI backend are introduced. GitHub Pages remains on main. Source changes are published only to archive/year2, preserving existing history and visibility. The old Netlify project is not modified.

Original Year2 source folders are unchanged. Known external-service and browser limitations are in README.md. User experience scores apply only to the revision actually reviewed.
